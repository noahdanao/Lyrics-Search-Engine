# Lyrics-Search-Engine
This C++ implementation of a search engine designed to process lyric datasets for managing and searching for specific words. The search engine is built to handle a file based on various lyric data utilizing C++ implementation to prompt, load, and facilitate song results.
The Core functionality goes as follows: 
  - User inputs a specific filename they choose to put into program
  - The searchEngine function will filter throughout the .txt to find the specific word, phrase, and/or sentence the user is attempting to search for
  - Designed to result in quick finds.
