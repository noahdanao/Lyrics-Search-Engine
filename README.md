## About
This project processes `.txt` lyric files to find specific words or phrases. It’s designed to be fast and lightweight, handling file input and search results through the terminal.

## Features
* **Custom Loading:** Input any `.txt` file at runtime.
* **Smart Filter:** Search for specific words, phrases, or full sentences.
* **Fast Results:** Optimized for quick retrieval from large datasets.

## Tech Stack
* **Language:** C++
* **Libraries:** STL (iostream, fstream, string)

## Getting Started
1. **Compile:** `g++ -o search main.cpp`
2. **Run:** `./search`
3. **Input:** Enter your filename and search term when prompted.
